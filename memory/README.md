# Memory

Accepted operational lessons live in `lessons.json` (machine-readable) and `LESSONS.md`
(rendered). Both are written only by the Memory Curation Workflow after the repository owner
labels a `type:memory` proposal issue `memory:accept`. Proposals come from completed runs and must
name supporting runs, evidence links, scope, confidence and a revalidation condition. Lessons can
never change security boundaries, cost limits, acceptance thresholds, publication permissions or
user requirements.
